# Brand for videos

- `tokens.css`: colours, font, safe area and minimum text sizes. Link it from every clip's `src/index.html`.
- Font: Montserrat (OFL). Copy the woff2 files from `elearning-course/scorm-plans/00_program/brand/fonts/` into the clip's `public/fonts/`. Never download them from a CDN at render time.
- Characters: copy the PNG poses you need, **unmodified**, from `elearning-course/scorm-plans/00_program/characters/assets/` into the clip's `public/characters/`. Never generate, redraw or recolour Noor or Dr. Omar.
- Logo: `scorm-plans/00_program/brand/assets/`. Use it only on the first and last scene.
