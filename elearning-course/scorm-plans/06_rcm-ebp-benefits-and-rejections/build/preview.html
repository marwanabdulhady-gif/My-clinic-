The rejection lands in your queue. What do you do first?

  • Nothing has changed, so the payer will reject it again for the same reason. A rejection comment tells you what to fix.

  • A second claim for the same visit is duplicate billing — a new rejection, not a fix.

  • Best choice. The fix starts in the note: as in Part A, the claim can only be as specific as the documentation behind it.

The note shows fever for 3 days, dysuria and a positive urinalysis. How do you fix the claim?

  • Best choice. Part A again: code the most specific diagnosis the findings support (a provisional one is acceptable) and let the findings justify it. The SME confirms the example diagnosis.

  • A code the note does not support is a coding error and an audit risk. Only code what is documented.

  • The symptom alone is exactly what the payer rejected. The findings point to a more specific diagnosis; use it.

The diagnosis and findings are corrected. How do you send it back?

  • A new claim for a service already claimed is duplicate billing and will be rejected. Resubmit the original with the supporting document.

  • Best choice. Rework, don't duplicate: the corrected claim goes back with the evidence the payer asked for.

Family planning covers hormonal contraceptives and IUDs.

Alcohol use is included, but hypnosis and rehabilitation are excluded from the mental-health benefit.

Home care for inpatients covers IV medicines, wound care and catheter care after the stay.
