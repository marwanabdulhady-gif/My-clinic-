# My Clinic brand kit (e-learning)

![My Clinic logo](logo-preview.png)

- **[`brand-identity.md`](brand-identity.md)** — the brand guide for designers and AI agents: logo rules, colours, fonts, icons, illustration style, AI image prompt template, screen layouts L1–L6.
- [`brand-kit.json`](brand-kit.json) — the same brand as data, for `brand_to_theme` in edumints.
- [`assets/`](assets/) — official logo files (navy, white, on-navy), the five-petal mark, and the four value tiles, taken from My Clinic's own decks.
- [`screen-mockups/`](screen-mockups/) — eight branded screen mockups (PNG; L1–L6 plus guides/tip variants) and their HTML source.

- [`fonts/`](fonts/) — locally bundled Montserrat/Tajawal, OFL licences and checksum provenance for the provisional draft review renderer. Marketing D11 remains open.
