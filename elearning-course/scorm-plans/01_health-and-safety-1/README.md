## Design idea in one paragraph

The source is a nine-module new-staff programme aligned to CBAHI, MOH codes and ISO 45001. It is mostly text-on-slides. The SCORM version keeps the nine sections as an outline menu, cuts each section to one idea per screen, and turns every list into a decision the learner has to make: sort RACE and PASS, read an NFPA diamond, triage a spill, find hazards in a corridor, stop using an overdue device, place a dose reading in the right band. The section checks feed one results breakdown, so the learner and the Safety Manager can see which plan needs another look.
