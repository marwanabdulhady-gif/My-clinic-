# Phase 1 — Action map & objectives (01 Facility Management & Safety)

## 1. Business goal

Every new staff member can act correctly in the first minutes of a facility emergency and spots and reports physical hazards before they cause harm. Measured by: CBAHI FMS survey interviews (staff knowledge), drill performance, and near-miss reporting volume.

## 2. Action map (what people must **do**, not just know)

| # | On-the-job action | Why people get it wrong | Practice in the module |
|---|---|---|---|
| A1 | Announce the right emergency code with location and name | Codes look alike; extensions differ by site | Code flashcards → code matching → "which code?" scenarios |
| A2 | Respond to a fire using RACE, use an extinguisher with PASS | Instinct is to fight the fire first; wrong extinguisher | Sort RACE and PASS; fire scenario; class drag-and-drop |
| A3 | Choose the right evacuation type | Use of elevators; full evacuation too early | Evacuation tabs + scenario MCQ |
| A4 | Recognise a hazard and choose the strongest control | PPE treated as the first control | AREC diagram; hierarchy sorting; corridor scenario |
| A5 | Read chemical labels (GHS, NFPA) before handling | Labels ignored; unlabelled containers accepted | Pictogram matching; NFPA diamond quiz |
| A6 | Decide when a spill is Code Orange and respond | Threshold unclear | Spill decision scenario |
| A7 | Segregate waste correctly; never recap sharps | Mixed bins | Waste drag-and-drop |
| A8 | Stop using equipment that is overdue, damaged or unlabelled, and report it | Pressure to keep working | Biomedical scenario |
| A9 | Follow access, ID, visitor and no-smoking rules | Habit | Security MCQ scenario |
| A10 | Protect self in radiation/laser areas (time, distance, shielding; dosimeter; MRI screening) | Unclear what applies to non-radiology staff | ALARA diagram; dose-band MCQ; laser class matching |
| A11 | Use the right to stop unsafe work and know who to contact | Fear of blame | Rights accordion inside the corridor scenario |

## 5. Pedagogy notes

- **Action Mapping**: every scored screen maps to an action A1–A11; content that maps to no action (e.g. long lists of firefighting equipment) becomes an explore screen, not a quiz.
- **Constructivist practice**: scenarios come before the rule recap where possible (the learner tries, gets feedback, then sees the rule).
- **Spaced retrieval**: the capstone (`hs1-950`) mixes codes, fire, hazmat and biomedical in one event, so learners retrieve across sections.
