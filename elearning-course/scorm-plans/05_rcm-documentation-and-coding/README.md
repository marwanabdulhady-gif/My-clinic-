## Design idea in one paragraph

The script's core message is "the payer does not see your patient; the payer only sees your documentation". Physicians are busy and sceptical of billing training, so the module stays clinical: every screen is a note, a code or an order decision a doctor makes daily. Learners compare a weak and a strong note, rebuild the clinical picture in order, swap symptom codes for supported diagnoses, sort codes the policy doesn't cover, decide what labs to order for a joint-pain patient, and finish by fixing three real-style notes in a short case game. Coverage details (the new EBP) are left to Part B, so this package is about **writing the note right**.
