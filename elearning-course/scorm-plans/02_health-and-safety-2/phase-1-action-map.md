# Phase 1 — Action map & objectives (02 Safety in Practice)

## 1. Business goal

New staff behave correctly in drills and real events from week one: fewer drill errors (wrong order, wrong extinguisher, elevator use), more hazards reported, and correct spill handling.

## 2. Action map

| # | On-the-job action | Common error | Practice |
|---|---|---|---|
| A1 | Spot hazards in a work area and rate the risk | Clutter and cables seen as "normal" | Store-room hotspot + risk worked example |
| A2 | Run the first minutes of a Code Red | Calling before rescuing; incomplete call; forgetting O₂ | Code Red drill game |
| A3 | Choose an evacuation tool for the patient in front of you | Carrying patients by hand; using elevators | Tool-to-patient drag-and-drop |
| A4 | Read an evacuation plan legend | Not knowing where the call point or assembly point is | Labelled floor-plan quiz |
| A5 | Pick the right extinguisher for the fire | Water on electrical or oil fires | Fire-scene drag-and-drop |
| A6 | Triage a spill and use the right kit | Over- or under-calling Code Orange; wrong kit | Spill triage scenario + spill-kit sort |
| A7 | Check a chemical's register row, SDS and NFPA before use | Using chemicals with no SDS on file | Register exercise |
| A8 | Keep prohibited items out of the facility | Heaters, extensions in offices | Allowed / prohibited sort |

## 5. Pedagogy notes

- Problem-first: each block opens with an activity; the poster-style source images become the **feedback** (the rule appears after the attempt).
- Retrieval practice of module 01 facts; new content (spill-kit steps, evacuation tools, register) is taught with a worked example before practice.
- Game elements serve the objective: lives in the Code Red drill model "you can recover from one mistake", not points for their own sake.
