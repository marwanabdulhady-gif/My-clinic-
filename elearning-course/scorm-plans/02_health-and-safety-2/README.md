## Design idea in one paragraph

Health & Safety 2 covers much of the same ground as module 01 but as posters and photos: hazard spotting, the RACE steps one by one, evacuation tools, extinguishers, Code Orange, GHS, NFPA, a real chemical register, spill kits and prohibited items. Repeating 01 would waste the learner's time, so this package is a **hands-on lab**: learners find hazards in a store room, run a Code Red drill as a branching game, pick the right evacuation tool and extinguisher, triage spills, work through a chemical register, and finish with a short "chemical store" escape room. Every activity uses facts already taught in 01, so this is retrieval practice in realistic settings, plus the content 01 does not have (the spill-kit procedure, evacuation tools, the register exercise, the bilingual code poster).
